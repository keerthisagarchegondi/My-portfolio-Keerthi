When the scoring rule changes the story

Project 9 — Point-adjustment evaluation audit

The Story

A scoring rule can grant more credit than the alerts earned. This synthetic study asks how a point-adjustment rule changes evaluation when the predictions themselves remain random.

See the Mechanism

An anomaly event is a contiguous run of anomalous timestamps. Raw pointwise scoring gives credit only at alerted timestamps. Point adjustment gives event-level credit after any alert touches that event.

The Experiment

The frozen design holds the random alert process fixed, varies event length and alert probability, and compares paired raw and adjusted F1 across 2,000 repetitions per condition.

Results

In the frozen primary condition (q=0.01; event length=200), mean F1 is 0.017 under raw pointwise scoring and 0.833 under point adjustment. This is a property of the declared synthetic scoring setup, not a detector benchmark.

Why It Matters

Evaluation rules should be reported with the same care as models. Limits: synthetic labels, label-independent random scores, no trained detector, and retrospective use of event boundaries. This is a reproducible research artifact, not peer-reviewed or published work.
